# Node.js 18 Sample Project

This is a sample Node.js 18 project that demonstrates a basic Express server setup.

## Prerequisites

- Node.js 18 or higher
- npm (comes with Node.js)

## Installation

1. Clone this repository
2. Install dependencies:
```bash
npm install
```

## Running the Application

Development mode (with auto-reload):
```bash
npm run dev
```

Production mode:
```bash
npm start
```

## Testing

Run the test suite:
```bash
npm test
```

## Features

- Express.js server
- JSON response handling
- Development mode with auto-reload (nodemon)
- Jest testing setup
- Node.js version display

## API Endpoints

- `GET /`: Returns a welcome message and the current Node.js version
